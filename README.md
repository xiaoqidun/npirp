# NPIRP
强制努比亚软件包安装程序回归纯粹

# 实测机型
努比亚 Z80 Ultra（Android 16，NebulaAIOS2.0.26MR_NX741J）

# 使用说明
1. 安装 APK，并在 LSPosed 中启用模块。
2. 确认模块作用域仅包含“软件包安装程序（`com.android.packageinstaller`）”和“设置（`com.android.settings`）”，并重启手机使模块生效。
3. 模块生效后会隐藏“纯净安装模式”及其设置入口，移除厂商安全提示、广告推荐和联网扫描等附加流程，直接显示应用权限与安装确认，让软件包安装程序回归纯粹。
